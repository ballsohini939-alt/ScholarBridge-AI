# 🎓 ScholarBridge AI

### A Student Support Platform for Scholarships, Internships, and Career Preparation

ScholarBridge AI is a React-based student support prototype designed to help students explore scholarship schemes, discover internship portals, compare their profiles with listed criteria, and organize their application journey in one place.
The project focuses on making opportunity discovery and student planning more organized and accessible.

## 🌐 Live Demo

**Live Website:** https://scholar-bridge-ai-ebon.vercel.app/
**GitHub Repository:** https://github.com/ballsohini939-alt/ScholarBridge-AI

## ✨ Features

* **Dashboard:** View an overview of your activities and student journey.
* **Find Opportunities:** Explore scholarship schemes and internship portals through official provider websites.
* **Eligibility Matcher:** Compare your student profile against criteria recorded in the app, with clear explanations of missing information and verification limitations.
* **Saved Opportunities:** Keep track of opportunities you want to revisit.
* **Application Tracker:** Organize and monitor your application progress.
* **Student Profile:** Maintain your education details, skills, and interests.
* **Rule-Based Assistant:** Get predefined guidance about scholarships, internships, profile improvement, and eligibility matching.
* **Learning Hub:** Explore learning guidance and organize your development goals.
* **Task Planning:** Keep track of learning and application-related activities.

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd ScholarBridge-AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🔎 Important Limitations

ScholarBridge AI is a prototype for student opportunity discovery and planning.

* **Eligibility matching is informational.** It compares profile information against criteria entered in the application and does not establish official eligibility.
* **Official verification is required.** Scholarship requirements, application dates, documents, and eligibility conditions must be checked with the relevant provider.
* **Internship listings link to a discovery portal.** The application does not currently retrieve or verify live internship vacancies.
* **The assistant is rule-based.** It uses predefined responses rather than a generative AI model.
* **Data is stored locally.** Profile information, saved opportunities, and tracker data use browser storage; the application does not currently provide a backend account system or cloud synchronization.

## 🔐 Privacy and Security

Do not enter sensitive personal information into the prototype. Browser-stored data may be lost if browser storage is cleared and is not automatically synchronized across devices.
